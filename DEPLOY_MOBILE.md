# Обновление SNOOPY3D SHOP с Android

**Важно:** сначала сделайте резервную копию опубликованного `index.html` (GitHub → файл → Download raw file). Новая версия использует **несколько файлов**, в отличие от старой однофайловой версии.

1. Распакуйте ZIP на смартфоне.
2. Откройте https://github.com/snoopy-3d/snoopy3d-shop и выберите Add file → Upload files.
3. Загрузите `index.html`, `style.css`, `app.js`, `config.js`, `.nojekyll` и `README.md` **в корень** репозитория. При необходимости включите в браузере «Версия для ПК». Не загружайте ZIP как файл.
4. Подтвердите Commit changes в `main`. Проверьте главную страницу, мобильное меню, корзину и переключение тем.
5. Файлы `supabase/schema.sql` и `supabase/functions/place-order/index.ts` предназначены для настройки Supabase; GitHub Pages не исполняет их. Сохраняйте структуру каталогов при загрузке или настройте Supabase отдельно.
6. Создайте Supabase проект, запустите SQL, создайте администратора через Auth и заполните `config.js` только публичными URL и anon key. До подключения базы реальные заявки недоступны.
7. Настройте Edge Function и уведомления, затем протестируйте доставку. Не публикуйте service_role, токен Telegram-бота или пароли.

**Безопасность:** до публичного приёма заявок добавьте антиспам/rate limiting. В России также проверьте применимые требования к обработке персональных данных и место хранения данных. Для коммерческого магазина GitHub Pages может не подходить по условиям использования; для постоянного размещения рассмотрите Cloudflare Pages.
