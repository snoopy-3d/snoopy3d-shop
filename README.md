# SNOOPY3D SHOP — рабочая основа v2

## Что уже работает локально
Адаптивная главная, каталог с поиском и категориями, корзина (localStorage), 6 тем, неоновые hover-эффекты, мобильное меню, формы заказа/услуг, вход супер-администратора и создание, редактирование и удаление товаров при подключении Supabase, просмотр заказов и смена статусов.

## Что пока НЕ готово
Это не опубликованный магазин. Демонстрационные товары показываются только до подключения базы. Без Supabase заявки не отправляются. Услуги пока редактируются в исходном коде. Загрузка файлов в Storage, полноценный редактор страниц, галерея, отзывы, восстановление пароля, антиспам, юридические страницы и тестирование реальной доставки уведомлений ещё требуют работы. Серверная функция рассчитана на Resend с подтверждённым отправляющим доменом; бесплатный email @bk.ru может быть получателем, но не произвольным адресом отправителя. Защита от спама/rate limiting обязательна перед публичным запуском.

## Установка
1. Создать отдельный репозиторий `snoopy-3d/snoopy3d-shop`, загрузить содержимое этой папки (не ZIP целиком). GitHub Settings → Pages → Deploy from branch → main/root. Сайт будет по адресу `https://snoopy-3d.github.io/snoopy3d-shop/`.
2. Создать Supabase проект. В SQL Editor выполнить `supabase/schema.sql`.
3. В Supabase Authentication отключить публичную регистрацию. В Auth → Users создать **одного** пользователя `snoopy.3d@bk.ru` с новым уникальным паролем (не пароль от почты), затем скопировать UUID и выполнить SQL INSERT в таблицу admins, как указано в schema.sql. Не делиться паролем в чате.
4. В `config.js` указать **только** Project URL и anon/publishable key Supabase. Не публиковать service_role.
5. Установить Supabase CLI, выполнить `supabase login`, `supabase link --project-ref <ref>`, затем развернуть `supabase functions deploy place-order --no-verify-jwt`. Для функции без JWT обязательно добавить CAPTCHA, лимит запросов и защиту от ботов перед реальным запуском.
6. Через `supabase secrets set` задать `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `RESEND_API_KEY`, `MAIL_FROM`, `ALLOWED_ORIGIN=https://snoopy-3d.github.io`. MAIL_FROM — подтверждённый отправитель Resend, а не произвольная почта @bk.ru. Для продакшена нужен подтверждённый домен отправителя.
7. Проверить: добавление товара через админку, просмотр каталога, оформление тестовой заявки, получение письма на snoopy.3d@bk.ru и Telegram, подтверждение покупателю, изменение статуса. Если уведомление не доставлено, заказ остаётся в базе; проверять логи функции.

## Безопасность
RLS включён. Публичные посетители видят только активные товары; заказы читает только admin. Сервер пересчитывает стоимость по базе, а не доверяет браузеру. В публичном репозитории не хранить секреты. Для коммерческого запуска потребуются политика конфиденциальности, согласие на обработку данных и механизм удаления персональных данных.
