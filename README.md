# SNOOPY3D SHOP — GitHub mobile upload

## Публикация демонстрационной витрины

Загрузите **index.html** в корень ветки `main` репозитория `snoopy-3d/snoopy3d-shop`. Это самодостаточный файл со стилями и скриптами, поэтому не требуется загружать папки или дополнительные файлы.

Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.

Адрес после публикации: https://snoopy-3d.github.io/snoopy3d-shop/

## Важно

Это демонстрационный фронтенд. Встроены адаптивная витрина, поиск, категории, локальная корзина, 6 цветовых тем и неоновое оформление. Демонстрационные товары и цены — вымышленные.

**Реальные заказы, SUPER ADMIN и email/Telegram-уведомления не работают без отдельной настройки Supabase и серверной функции.** Для запуска продаж необходимы антиспам, юридические документы и тестирование. Не вставляйте пароли, токены Telegram или service_role в index.html.

Исходники для дальнейшей разработки и серверные файлы находятся в отдельном архиве `SNOOPY3D_SHOP_SOURCE_AND_BACKEND.zip`.
