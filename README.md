# SNOOPY3D SHOP

[Витрина магазина](https://snoopy-3d.github.io/snoopy3d-shop/) опубликована на GitHub Pages. Supabase хранит каталог, заказы товаров и заявки на услуги. Сайт показывает активные товары из базы. Если каталог недоступен, витрина сообщает об ошибке загрузки.

## Управление магазином

Вход в SUPER ADMIN выполняется с адресом `snoopy_3d@bk.ru` и паролем этой учётной записи Supabase. Права определяются таблицей `public.admins` по UID пользователя. В панели можно редактировать товары и фотографии, просматривать состав заказов и описание услуг, менять статус заявки. Виды услуг редактируются в `index.html`.

## Развёртывание

1. GitHub Pages публикует корень ветки `main` репозитория `snoopy-3d/snoopy3d-shop`.
2. Для **нового** проекта Supabase выполните `schema.sql` из корня репозитория в SQL Editor. Он задаёт права на каталог, заказы, админку и хранилище фотографий.
3. В Supabase Auth создайте подтверждённую учётную запись владельца и добавьте её UID в `public.admins` по инструкции в схеме. Пароль сайта задаётся отдельно от пароля почты.
4. В `config.js` укажите URL Supabase и публичный ключ. Секретный ключ сервера хранится только в Supabase.
5. Код функции находится в `index.ts` в корне. В Supabase Edge Functions откройте функцию со slug `place-order` и обновите её код. Для другого адреса витрины измените разрешённый origin в функции.
6. Оформите заказ товара и заявку на услугу с витрины. Сверьте номера и поля в SUPER ADMIN. Проверьте изменение статуса.

## Уведомления владельцу

После записи заявки `place-order` отдельно отправляет письмо и сообщение в Telegram. Чтобы включить каналы, добавьте секреты в Supabase Edge Functions → Secrets.

| Канал | Секреты | Получатель |
| --- | --- | --- |
| Email через Mail.ru | `MAIL_SMTP_PASSWORD` | `snoopy_3d@bk.ru` |
| Email через Resend | `RESEND_API_KEY`, `MAIL_FROM` | `snoopy_3d@bk.ru` |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Чат, указанный в `TELEGRAM_CHAT_ID` |

Для Mail.ru создайте [пароль внешнего приложения](https://help.mail.ru/mail/login/mailer/#password) для `snoopy_3d@bk.ru` с правом «Только отправка писем в Почте». Сохраните его как `MAIL_SMTP_PASSWORD`. Функция отправляет письма через `smtp.mail.ru:465` по TLS от этого адреса на этот же адрес.

Если `MAIL_SMTP_PASSWORD` отсутствует, функция использует Resend при наличии его настроек. `MAIL_FROM` задаёт адрес отправителя на подтверждённом домене. Для Telegram бот должен иметь доступ к указанному чату. Храните пароли и токены только в секретах Supabase.

Ответ функции содержит номер заявки и статусы `notification_status` и `telegram_status`. Значение `not_configured` означает, что канал пропущен из-за отсутствующей настройки. `accepted` означает, что запрос принят сервисом. Проверяйте доставку по фактическому письму и сообщению с тем же номером. При сбое отправки заявка остаётся в базе.

## Доступ к данным

RLS ограничивает витрину активными товарами и доступ к заказам администратором. Функция проверяет товары и вычисляет цену по каталогу на сервере. Приём заявок открыт для гостей. Для публичного использования требуется ограничение частоты заявок и защита от спама.
