SNOOPY3D SHOP — Neon Glass
Версия: 2026-11-10

ФАЙЛЫ В КОРНЕ АРХИВА:
index.html — структура сайта и навигация
style.css — оформление Neon Glass и адаптация под смартфоны
app.js — каталог, товар, корзина, формы, админ-панель
config.js — публичные параметры Supabase
.nojekyll — для GitHub Pages

УСТАНОВКА С ТЕЛЕФОНА:
1. Сначала сохраните резервную копию текущих index.html, style.css, app.js, config.js.
2. Распакуйте ZIP на телефоне. Загрузите файлы из корня архива в корень репозитория snoopy-3d/snoopy3d-shop (НЕ загружайте сам ZIP как сайт).
3. При запросе GitHub подтвердите замену существующих файлов и сделайте Commit.
4. Дождитесь публикации GitHub Pages, затем обновите сайт с очисткой кеша.
5. Проверьте каталог, фотографии, вход администратора, корзину и оформление заявки.

ВАЖНО:
- Товары и заказы остаются в существующей базе Supabase. В ZIP нет базы данных.
- Уведомления по email и Telegram выполняются серверной Edge Function place-order; этот ZIP её не меняет. Успешная доставка уведомлений не подтверждена.
- Вход администратора проверяется Supabase RPC is_admin; указывайте реальный адрес учётной записи Supabase Auth.
- Страница «Заказы» показывает сохранённый на устройстве номер последней заявки и способ запросить статус. Она не раскрывает чужие заказы и не обещает автоматическую проверку статуса.
- Этот ZIP основан на локальном исходном пакете проекта, дополненном новыми элементами. Текущий GitHub app.js мог измениться позже: перед заменой обязательно сохраните резервную копию. Прямой тест с боевым Supabase и доставкой писем не выполнялся.
